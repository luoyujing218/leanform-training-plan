# LEANFORM 网站发布包

此目录包含静态网站，可部署到 GitHub Pages、Cloudflare Pages 或 Netlify。

## GitHub Pages 快速发布
1. 在 GitHub 新建一个仓库。若设置为公开，仓库源代码和训练计划也会公开。
2. 上传本目录中的全部文件和 `mobile-cards` 文件夹（保持目录结构）。
3. 仓库设置中进入 Pages，选择从 `main` 分支根目录发布。
4. 等待 Pages 发布后，将提供的网址分享给其他人。

体重、训练完成状态和健康记录保存在每个人自己的浏览器中，不会自动同步到他人设备或形成共享数据库。此版本发布副本隐藏了原网站上的当前体重数字和个人睡眠/减重描述。
